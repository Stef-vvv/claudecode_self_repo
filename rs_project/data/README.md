# 数据文件说明

## 数据来源

本工程使用Eyeriss V1论文中描述的卷积层数据进行验证。具体为VGG-16网络的第3层卷积 (Layer-3 Conv2D)。

## 文件清单

| 文件 | 值数量 | 格式 | 说明 |
|------|--------|------|------|
| `conv2.input.real.dat` | 8,192 | Q0.8浮点 (步长1/256) | 输入特征图 16×16×32 |
| `conv2.real.dat` | 18,432 | Q0.8浮点 (步长1/256) | 权重 64×32×3×3 |
| `conv2.output.real.dat` | 16,384 | Q0.8浮点 (步长1/256) | 参考输出 64×16×16 |
| `golden_q8_output.dat` | 16,384 | Q0.8浮点 | 独立计算验证的标准输出 |

## 数据量计算

- **IFMAP 8,192**: 32通道 × 16行 × 16列 = 8,192个Q8值
- **FILTER 18,432**: 64输出通道 × 32输入通道 × 3行 × 3列 = 18,432个Q8值
- **OFMAP 16,384**: 64输出通道 × 16行 × 16列 = 16,384个Q8值

## 数据格式 (Q0.8 定点数)

每个值 = 整数 / 256。例: `0.0234375 = 6/256`, `-0.01953125 = -5/256`

范围: [-0.5, 0.49609375] (对应Q8有符号范围[-128, 127])

## 标准输出的验证

`conv2.output.real.dat`的正确性已通过独立numpy整数计算验证:
```
OFM[f][h][w] = SAT[-127,127]( SUM_c SUM_kh SUM_kw (
    IFM_Q8[c][h+kh-1][w+kw-1] × FILT_Q8[f][c][kh][kw]
) >> 8 )
```

验证结果: **16,384/16,384 完全匹配** (使用对称饱和[-127,127], 无ReLU)

## 文件格式

每行一个浮点数值。通道优先(F/C优先)顺序存储:
- IFMAP: [ch0_row0_col0..15, ch0_row1_col0..15, ..., ch31_row15_col0..15]
- FILTER: [f0_c0_kh0_kw0..2, f0_c0_kh1_kw0..2, f0_c0_kh2_kw0..2, f0_c1_..., f1_c0_...]
- OFMAP: [f0_row0_col0..15, f0_row1_col0..15, ..., f63_row15_col0..15]
