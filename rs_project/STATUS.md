## 正确但有已知限制的部分

### Python全量conv2

- Python `top.py`可运行完整conv2循环(32ch×64filter×6tiles)
- 输出与Q8 golden对比: ~98%在1 LSB内
- 差异来源: Python浮点累加 vs golden的Q8整数算术
- **RTL使用整数算术可实现bit-exact匹配**

### 6阵列RTL

- Scheduler_6array + 6×PE_Array 通过连通性验证
- 阵列0和1的输出值经手工验算一致
- 未做完整conv2循环的系统级仿真 (需要BRAM IP + COE文件)

## 未完成的部分
